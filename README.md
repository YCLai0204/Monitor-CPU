# Monitor-CPU

一隻在工具列上爬來爬去的吉祥物（目前是 🦀 螃蟹）。**CPU / GPU 負載越高，牠就跑得越快、顏色也從青色越變越紅。**

- 0% → 青色，慢慢晃、偶爾停下來吐泡泡
- 50% → 黃綠色，穩定地橫著走
- 100% → 全紅、腳踩得飛快，身上還會冒熱氣

滑鼠移到吉祥物身上會顯示即時數值，**左鍵**戳牠會嚇跑牠（並固定顯示數值），**雙擊**牠或**左鍵點右下角的小圖示**會打開設定視窗，**右鍵**叫出精簡選單（設定… / 離開）。其他時候整個視窗都是穿透的，不會擋到你原本的工具列或其他視窗。

右下角的小圖示也是一隻螃蟹，會像 OneDrive 的雲一樣直接顯示在時鐘旁邊，顏色一樣跟著負載從青色變紅色。

### 活動範圍

設定視窗的「**可以在整個畫面活動**」是每種吉祥物共用的開關：**關掉**就只在底下的工具列上活動；**打開**的話視窗會蓋滿整台螢幕（一樣整片穿透、不擋任何東西），吉祥物可以到畫面的任何地方。打開後還可以再勾「**到其他視窗上**」（螃蟹叫「爬到其他視窗上」、小鳥叫「停在其他視窗的標題列上」）。

新增動物時：

1. 寫一支畫法（例如 `src/renderer/bear.js`），掛到 `window.MascotArt`，並在 `index.html` 載入
2. 在 `src/renderer/app.js` 的 `MASCOT_DEFS` 加一筆：選用哪一套動作（`crawl` 像螃蟹爬、`fly` 像小鳥飛、`swim` 像綠蠵龜游），再依需要打開 `climber`（不倒掛、從視窗側邊爬上去）、`food`（偷偷放食物）、`foodReach`（站在食物旁邊吃，食物留在原地）、`run`（負載高時衝刺）、`curl`（被戳到捲成球）等選項
3. 在 `src/main/main.js` 與 `src/renderer/settings.js` 的 `MASCOTS` 各加一筆；settings.js 那筆的 `group` 決定牠在角色下拉選單的哪一區（`sky` 天上、`water` 水裡、`land` 地上）

這兩個活動範圍的開關不用另外做。

### 螃蟹在整個畫面爬

打開「可以在整個畫面活動」後，螃蟹不只在工具列上走，還會**爬上左右兩側的牆、倒掛在天花板上**，轉角時身體跟著轉過去。

打開「**爬到其他視窗上**」的話，螃蟹會不時挑一個視窗：沿著牆爬到天花板、走到那個視窗正上方，**放手跳下去**，在空中翻正後落在視窗頂端，接著**沿著那個視窗的四周爬**（上緣、兩側、倒掛在底部）。視窗被拖動時跟著走；待一陣子後會從視窗側邊或底部跳下來，落在下面的視窗或工具列上。視窗關掉、縮小或最大化時，螃蟹直接掉下來。

用滑鼠抓起來時會轉正，放開就往下掉，落在第一個碰到的視窗頂端或工具列上。

### 小鳥

設定視窗的「角色」可以換成一隻小鳥（鳳梨綠頰鸚哥：灰褐色頭頂、白色眼圈、橘紅臉頰、紅橘色肚子、綠色翅膀、暗紅長尾巴）。跟螃蟹一樣是 Canvas 畫出來的向量圖，不吃圖檔。

停著的時候會自己找事做：走路、跳一跳、東張西望、歪頭、低頭啄、理毛、伸展單邊翅膀、拍拍翅膀；過一陣子就**起飛**，在空中繞幾圈再找地方**降落**（落地會壓扁一下）。飛行時身體往前進方向傾斜、頭看著前方，往下滑翔時翅膀拍得慢。

**負載越高越過動**：

- 休息的時間越短、越常起飛，飛得越快，降落前繞的圈越多
- 70% 以上開始**飛得歪七扭八**，偶爾還會**翻跟斗**；停著的時候一直跳、一直拍翅膀
- 55% 以上臉開始變紅，再高會冒汗

**右下角的小圖示是一隻搖頭的小鳥**，負載越高搖越快（約每秒 0.6 → 2.5 個週期）；畫面上飛的那隻不搖頭。

「可以在整個畫面活動」關掉時，小鳥在工具列上方走走跳跳，飛起來也只在螢幕底部那一條；打開時在畫面上到處飛。

到處飛的時候，可以再打開「**停在其他視窗的標題列上**」（跟螃蟹的「爬到其他視窗上」是同一個開關）：小鳥會降落在其他程式視窗的最上緣，視窗被拖動時跟著走，視窗關掉、縮小或被別的視窗蓋住就飛走。最大化的視窗頂端貼著螢幕上緣，小鳥站不上去，所以不會停在那裡。

> 視窗位置是用一個常駐的 PowerShell 呼叫 Windows 內建的 `user32` / `dwmapi` 每 200ms 讀一次（`src/main/window-watcher.js`），沒有原生 npm 套件；只有在整個螢幕模式、而且開了這個選項時才會執行。

`src/public/` 放的是當初設計小鳥的參考照片，不會被打包進 exe。

### 台灣黑熊

設定視窗的「角色」可以換成 Q 版的台灣黑熊（黑色身體、胸前米白色的 V 字、咖啡色口鼻）。

- 平常正面看著你，走路時臉才轉向前進方向，腳掌也跟著朝那一邊
- **負載 50% 以上改成四腳衝刺**：側面奔跑、速度 1.5 倍、後面揚起塵土，掉到 45% 以下才恢復兩腳走路
- 負載高時臉紅、冒汗

打開「可以在整個畫面活動」後，黑熊照真實的習性爬——台灣黑熊很會爬樹，但不會倒掛：

- 走到螢幕邊會**扒著牆往上爬**（身體直立貼著牆、四肢扒在牆上，往上爬就抬頭、往下爬就低頭），每次只爬到螢幕的三到五成高，東張西望一下就爬下來，**不會走到天花板**
- 打開「爬到其他視窗上」的話，會去**底部貼近工具列、搆得到的視窗**：走到旁邊、順著側邊爬上去，在頂端找個地方坐下來，坐一陣子再從旁邊有空間的那一側爬下來。太高搆不到的視窗不會去，也不會倒掛在視窗底部
- **偷偷放食物**：搆得到的視窗 20 秒沒被移動，頂端就會冒出兩顆青剛櫟果實（秋冬時台灣黑熊會爬到樹上吃），黑熊會跑去坐下來雙手捧著啃。一次只放一顆，吃完 25 秒內不會再放，2 分鐘沒吃掉就收掉
- 食物所在的視窗關掉、縮小、最大化，或食物被別的視窗蓋住時，**食物會掉下來**，落到下面的視窗頂端或工具列上，黑熊一樣會去吃
- 黑熊爬著的地方被別的視窗蓋住、或視窗不見了，黑熊也會掉下來（螃蟹一樣）

右下角的小圖示是黑熊的頭和胸前的 V 字。

### 黑面琵鷺

設定視窗的「角色」可以換成 Q 版的黑面琵鷺：白色身體、繁殖期的淡黃色冠羽（從後腦勺往後垂）與胸前黃斑、眼睛周圍到嘴巴根部的黑色臉，以及最好認的黑色長扁嘴，尖端像湯匙。

動作跟小鳥同一套：走走跳跳、東張西望、理毛、伸展翅膀，起飛後繞幾圈再降落；負載越高越過動，打開「可以在整個畫面活動」後到處飛、停在其他視窗的標題列上。不同的地方：

- 轉頭時長嘴也跟著轉過去
- 覓食時不是低頭啄，而是像真的黑面琵鷺一樣把湯匙嘴放低、左右掃

右下角的小圖示是黑面琵鷺的頭和湯匙嘴。

### 綠蠵龜

設定視窗的「角色」可以換成 Q 版的綠蠵龜（側面）：橄欖褐色的背甲上有放射狀紋路、米黃色的腹甲、頭上一塊塊淺色鱗片、長長的槳狀前鰭肢。

- **只在工具列上**：平常在工具列上慢慢爬（前鰭肢一起往後撐），過一陣子就**下水**——身邊冒出一片淺水，濺起水花，在水裡用前鰭肢像翅膀一樣划，水面有波浪、反光和划水的漣漪；游一陣子再**上岸**，水退掉、身上滴下水珠。工具列上哪裡都可以下水或上岸
- **可以在整個畫面活動**：把整個畫面當成海，在畫面上慢慢游、身後冒一串泡泡，累了游回工具列落進淺水休息
- 水生動物**不會到其他視窗上**，所以選綠蠵龜時「到其他視窗上」會變成灰色，也不會去偵測其他視窗
- 負載越高游得越快、越常待在水裡、水花越多，70% 以上游得歪七扭八
- 被戳到會嚇一跳、加速游走——海龜不能把頭縮進殼裡（陸龜才可以），所以不會縮頭

右下角的小圖示是整隻綠蠵龜。

### 台灣穿山甲

設定視窗的「角色」可以換成 Q 版的台灣穿山甲（側面）：全身一片片重疊的褐色鱗片、粉膚色的尖嘴小臉、粗粗的長尾巴、前腳的大爪子。

- 四腳慢慢走，前腳的大爪子往後收在腳掌下面（真的穿山甲是用指背走路，爪子才不會磨鈍）
- **被戳到會捲成一顆球**，縮個幾秒才打開；被抓起來、掉下來的時候也是一顆球——真的穿山甲遇到危險就是這樣
- **負載 60% 以上捲成球在地上滾**，速度 1.6 倍、後面揚起塵土，掉到 55% 以下才恢復用走的（這是 Q 版的誇張，真的穿山甲不會滾著走）
- 負載高時臉紅、冒汗

打開「可以在整個畫面活動」後，動作跟台灣黑熊同一套——穿山甲也會用爪子和尾巴爬樹，但不會倒掛：

- 走到螢幕邊會**扒著牆往上爬**（整隻轉成直的、四隻腳抓著牆，往下爬時頭朝下），爬到三到五成高就下來
- 打開「爬到其他視窗上」的話，會從**底部貼近工具列、搆得到的視窗**側邊爬上去，在頂端趴著休息
- **偷偷放食物**：搆得到的視窗 20 秒沒被移動，頂端就會冒出一座小白蟻窩，穿山甲會跑過去低頭伸長舌頭舔；食物掉下來、收掉的規則跟黑熊一樣
- 扒在牆上時被戳到，會捲成球直接掉下來

右下角的小圖示是穿山甲的頭和身體前半（大一點的圖示是整隻）。

## 需要什麼

只需要 [Node.js](https://nodejs.org/)（18 以上）。**不需要 Python、不需要編譯器、不需要管理員權限，也沒有任何原生套件要編譯** —— 這是刻意的，為了讓它在大部分電腦上都裝得起來。

## 怎麼跑

```bash
npm install
npm start
```

## 打包成單一 exe（給沒裝 Node 的電腦用）

```bash
npm run dist
```

產生的 `dist\Monitor-CPU <版本>.exe`（約 70 MB）是免安裝的可攜檔，複製到別台 Windows 電腦上雙擊就能跑，那台電腦不需要裝 Node 或任何東西。exe 的圖示就是螃蟹。

> `build.electronDist` 特意指向 `node_modules/electron/dist`。electron-builder 預設會再去 GitHub 抓一份 115MB 的 Electron，而它的 8 執行緒分段下載器在某些網路環境會整個卡死（而且不會逾時重試）。`npm install` 早就把同版本抓好了，直接用現成的既快又不會卡。

### 圖示

exe 圖示 `build/icon.ico` 是從 `src/renderer/crab.js` 的畫法產生的，跟工具列上那隻是同一份。改了螃蟹長相之後重新產生：

```bash
npm run icon
```

32px 以下的尺寸會自動改用線條較粗、省略細節的畫法，否則在檔案總管的小圖示裡會糊成一團。

## 設定視窗

雙擊吉祥物、左鍵點右下角的小圖示、或右鍵選單的「設定…」都可以打開。最上面會即時顯示 CPU / GPU 使用率，改了就立刻生效、自動儲存，關掉視窗不會結束程式。

| 項目 | 說明 |
| --- | --- |
| 角色 | **螃蟹**，或**小鳥**（見上方） |
| 大小 | 60% – 160% 的滑桿 |
| 跟著誰動 | 決定吉祥物的速度與顏色要跟著 **CPU**、**GPU**、還是**兩者取較高** |
| 可以在整個畫面活動 | 關掉只在工具列上；打開就到整個畫面（螃蟹沿著四周爬、小鳥到處飛），每種吉祥物都適用 |
| 到其他視窗上 | 打開整個畫面後才能設定：螃蟹「爬到其他視窗上」、小鳥「停在其他視窗的標題列上」 |
| 一直顯示數值標籤 | 是否一直顯示頭上的數值氣泡（關掉的話滑鼠移過去才會出現） |
| 在桌面顯示吉祥物 | 關掉的話工具列上就不會有吉祥物，只剩右下角的小圖示 |
| 在右下角顯示小圖示 | 關掉的話右下角就沒有圖示，改從吉祥物身上叫出選單 |
| 顯示在螢幕 | 多螢幕時決定吉祥物要待在哪一台 |
| 開機時自動啟動 | 登入 Windows 後自動跑起來（見下方） |
| 溫度顯示 N/A？ | 說明為什麼沒有溫度，以及怎麼補上 |
| 繪圖方式 | **自動**（預設）/ **省 GPU** / **用顯示卡**，見下方；改了要重新啟動，設定視窗會出現「重新啟動」按鈕 |

### 繪圖方式（GPU 用量）

吉祥物是一片透明視窗，每畫一格 Windows 都要把整片視窗重新合成到桌面上；打開「可以在整個畫面活動」時這片視窗是整台螢幕那麼大。為了不吃太多 GPU：

- 有在動時每秒畫 30 格，閒著（坐著、停著、只剩眨眼）時每秒 12 格；畫面沒變的那一格直接跳過，頭上的數值標籤也只在內容或位置變了時才更新
- **省 GPU**：關掉硬體加速、改用 CPU 繪圖，這個程式本身的 GPU 用量變成 0，只剩 Windows 合成畫面的部分，代價是 CPU 多用一點
- **用顯示卡**：CPU 用得最少
- **自動**：邏輯核心 8 個以上用「省 GPU」，少於 8 個（入門款筆電）用「用顯示卡」

在 Intel UHD 770 內建顯示卡、20 個邏輯核心的桌機上量到的（整台電腦多用的量，整個畫面模式）：

| 做法 | GPU | CPU |
| --- | --- | --- |
| 最初的版本（每秒 60 格） | 約 25～30% | 約 2.3% |
| 用顯示卡 | 約 11～15% | 約 1.2% |
| 省 GPU | 約 6～7% | 約 2.3% |

只在工具列上的時候大約是這些數字的一半。

### 開機時自動啟動

勾選後會寫入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `Monitor-CPU`。以前的版本有兩個問題，導致勾了也不會啟動：

1. portable exe 執行時其實是先解壓到暫存資料夾再跑，以前登錄檔記的是暫存資料夾裡那份，登出後就被清掉了。現在改記你實際點的那個 exe（electron-builder 提供的 `PORTABLE_EXECUTABLE_FILE`）。
2. Electron 寫入時不會幫路徑加引號，路徑有空白（例如使用者名稱「windows user」）時，Windows 會在空白處切斷路徑。現在路徑一律自己加引號。

每次啟動都會重新寫一次，所以**把 exe 搬到別的資料夾後，打開一次新位置的 exe** 就會更新成新路徑。`npm start` 跑起來的開發版也會寫入（指向 `electron.exe` + 專案資料夾），最後執行的是哪一份，開機就會啟動哪一份。

設定會存在 `%APPDATA%\Monitor-CPU\settings.json`。改名前的舊設定（`%APPDATA%\crab-monitor`）會在第一次啟動時自動複製過來。

### 螃蟹和小圖示不能同時關掉

這兩個是唯二能叫出選單的地方，全關掉就再也找不到設定了。所以只剩一個開著的時候，那一項會變成灰色並標示「至少要留一個」。

萬一還是找不到（例如手動改壞了設定檔），**再執行一次 exe 就會把吉祥物和小圖示兩個都叫回來，並打開設定視窗**，不會多開第二隻。

### 小圖示為什麼會直接顯示，而不是藏在 `^` 箭頭裡

Windows 11 預設會把新程式的系統匣圖示收進 `^` 箭頭，要自己到「設定 → 個人化 → 工作列 → 其他系統匣圖示」打開。那個開關其實存在登錄檔 `HKCU\Control Panel\NotifyIconSettings` 的 `IsPromoted`。

小圖示第一次出現時，程式會幫**自己的**那一筆打開，效果跟你在 Windows 設定裡手動打開一樣，不會動到其他程式的圖示。每個 exe 位置只會自動打開一次，之後你若在 Windows 設定裡把它收回去，程式會尊重你的選擇，不會再蓋掉。

Windows 10 用的是另一種格式，這個功能不會生效，要自己把圖示拖到工作列上。

## 數據是從哪裡來的

這是這個專案唯一比較麻煩的部分，所以分成好幾層，抓得到哪層就用哪層：

| 數據 | 來源 | 相容性 |
| --- | --- | --- |
| **CPU 使用率** | Node 內建的 `os.cpus()` 時間差 | ✅ 所有電腦、所有平台都可以 |
| **GPU 使用率** | ① `nvidia-smi`（有 N 卡就用）<br>② LibreHardwareMonitor 的 WMI<br>③ Windows 內建的 `GPU Engine` 效能計數器 | ✅ Win10/11 幾乎都有第 ③ 層，NVIDIA / AMD / Intel 通吃 |
| **CPU 溫度** | ① LibreHardwareMonitor 的 WMI<br>② ACPI 熱區 `MSAcpi_ThermalZoneTemperature` | ⚠️ 見下方說明 |
| **GPU 溫度** | ① `nvidia-smi`<br>② LibreHardwareMonitor 的 WMI | ✅ N 卡沒問題，其他卡見下方說明 |

效能計數器的名稱會隨 Windows 語言在地化（中文版叫「GPU 引擎」），所以程式會先去登錄檔 `Perflib` 把英文名字翻成當地名字再查，中文版 Windows 一樣抓得到。

### `npm start` 出現 `Cannot read properties of undefined (reading 'requestSingleInstanceLock')`

你八成是在 **VS Code 的整合式終端機**裡跑的。VS Code 會設一個 `ELECTRON_RUN_AS_NODE=1` 環境變數並傳給子程序，它會讓 electron 退化成普通的 Node，`require('electron')` 就拿不到模組。清掉它再跑：

```powershell
$env:ELECTRON_RUN_AS_NODE = $null
npm start
```

換一個獨立的 PowerShell 視窗跑也可以。打包出來的 exe 不受影響。

### 為什麼溫度顯示 N/A？

因為 **Windows 本身沒有提供通用的 CPU/GPU 溫度介面**。筆電通常有 ACPI 熱區可以讀，桌上型電腦的溫度多半只能透過主機板晶片直接讀取，這件事需要核心層驅動。

想看到溫度的話，裝並執行 [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)（免費開源）就好：

1. 下載後執行 `LibreHardwareMonitor.exe`
2. 到 `Options` → 勾選 **Remote Web Server 下方的 `WMI Provider`**
3. 讓它留在背景（可以縮到系統匣）

Monitor-CPU 會自動偵測到它開的 WMI namespace 並改用它的數據，**不用重開**，下一次取樣（約 2 秒）就會出現溫度。

> 注意：使用率不受影響，就算完全不裝 LibreHardwareMonitor，CPU 與 GPU 的使用率照樣正常運作，螃蟹也照樣會變色變快。

## 專案結構

```
src/
  main/
    main.js           Electron 主程序：置頂穿透視窗、系統匣、選單、設定視窗、開機自動啟動
    metrics.js        取樣邏輯（CPU 用純 JS，其餘交給 probe）
    probe.ps1         常駐的 PowerShell 取樣程序，每 2 秒吐一行 JSON
    window-watcher.js 常駐的 PowerShell，列出其他視窗的位置給小鳥找標題列停
    tray-icon.js      備用的點陣系統匣圖示（Canvas 版還沒畫好或畫失敗時才用）
  preload/
    preload.js          吉祥物視窗的 contextBridge，只開放需要的幾個方法
    settings-preload.js 設定視窗的 contextBridge
  renderer/
    index.html
    style.css
    crab.js        螃蟹的 Canvas 畫法（身體、螯、腳、眼柄、熱氣），也負責產生圖示
    bird.js        小鳥的 Canvas 畫法（走路、展翅、歪頭、啄、理毛、伸展、翻跟斗），也負責產生系統匣圖示
    bear.js        台灣黑熊的 Canvas 畫法（走路、衝刺、扒牆、坐著、吃東西）、青剛櫟果實、系統匣圖示
    spoonbill.js   黑面琵鷺的 Canvas 畫法（參數跟 bird.js 一樣，覓食時湯匙嘴左右掃）、系統匣圖示
    turtle.js      綠蠵龜的 Canvas 畫法（爬、游、被抓）、淺水（波浪、反光）、水花泡泡漣漪、系統匣圖示
    pangolin.js    台灣穿山甲的 Canvas 畫法（走路、扒牆、趴著、舔白蟻、捲成球、滾）、白蟻窩、系統匣圖示
    app.js         移動邏輯（螃蟹走路與沿著螢幕 / 視窗四周爬、小鳥的停留 / 飛行狀態機）、數值標籤、滑鼠命中判定
    settings.html  設定視窗（settings.css、settings.js）
scripts/
  make-icon.js     用 crab.js 產生 build/icon.ico
build/
  icon.ico         exe 圖示（16–256px）
  icon.png         256px 預覽
```

視窗是一條跨滿整個螢幕寬度、高 360px 的透明視窗（打開「可以在整個畫面活動」時則是蓋滿整台螢幕），貼在螢幕最底部並用 `screen-saver` 層級蓋在工具列上方；平常整片 `setIgnoreMouseEvents(true)` 讓點擊穿透到工具列，只有游標真的壓在螃蟹身上時才短暫接管滑鼠。

系統匣圖示會在螃蟹視窗載入後，用同一份 `crab.js` 一次畫好 21 種顏色（每 5% 一種）× 3 種解析度（16 / 24 / 32px）快取起來，所以跟工具列上的螃蟹長得一樣。
